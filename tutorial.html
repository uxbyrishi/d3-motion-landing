Preparing Your Animation & Dragging into Studio

Support for CSS keyframes, Canvas, Three.js, SVG, and HTML packages

D3 can render any web animation that executes in a modern browser. You can import animations in two simple formats:

Option A: Single Standalone .html File

Ideal for CSS keyframe animations, self-contained Three.js / Canvas scripts, inline SVG animations, or single-file UI prototypes. Simply drag the .html file straight into the studio window.

Option B: Multi-File .zip Archive or Folder

For complex projects with external CSS, JS libraries (GSAP, Three.js), local custom fonts, and images. Place an index.html at the root of the folder and compress it into a .zip.

Relative Paths Best Practice:

Always use relative paths in your HTML (e.g. href="./styles.css" and src="./bundle.js" instead of absolute paths like /styles.css). This ensures the embedded local server loads all assets properly.

Configuring 60 FPS & Exporting Broadcast MP4

Deterministic frame-by-frame capture • Zero dropped frames

Standard screen recording utilities (OBS, QuickTime, Loom) suffer from frame drops whenever heavy 3D shaders or complex layout reflows occur. D3 solves this fundamentally:

  • Deterministic Virtual Clock: D3 hooks into the browser's requestAnimationFrame loop and advances time manually by exactly 1/60th of a second per step.
  • Perfect Frame Capture: The engine waits until every single pixel, shader, and DOM element has finished rendering before snapping the frame.
  • Zero Jitter: Even if your laptop takes 200ms to render a heavy 4K 3D scene, the resulting MP4 plays back at a buttery-smooth, broadcast-locked 60 FPS.

Select Your Export Presets:

  1. Resolution: Choose 1080p Landscape (1920 × 1080), 4K UHD (3840 × 2160), 9:16 Vertical for Reels/Shorts/TikTok (1080 × 1920), or 1:1 Square (1080 × 1080).
  2. Duration: Set the exact duration in seconds (e.g. 5s, 10s, 30s) or let D3 auto-detect your CSS animation loop.
  3. Framerate: Select 60 FPS for ultra-smooth fluid UI motions, or 30 FPS / 24 FPS for cinematic styles.
  4. Click Render MP4. The static FFmpeg encoder instantly compiles frames into an H.264 (yuv420p) video ready for upload or video editors!

Pro Tips for Frontend & Motion Designers

Techniques to get the sharpest, fastest animation renders
  • Offline Web Fonts: If you use custom Google Fonts or Adobe Typekit, download the .woff2 or .ttf files and include them inside your ZIP folder using standard CSS @font-face. This guarantees instant font rendering without remote HTTP latencies.
  • High-DPI / Retina Crispness: For canvas animations, render your canvas at double resolution (width = 3840, height = 2160) to ensure vectors and text remain razor-sharp on 4K monitors.
  • Seamless Looping: Set your animation duration so that frame 0 and the final frame connect smoothly. D3 renders exact frame counts with sample-accurate cuts.
