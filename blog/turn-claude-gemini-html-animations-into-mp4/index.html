1. The Master Prompt Pattern for Video-Ready HTML

When asking Claude 3.7 Sonnet or Gemini 3.8 Flash to write motion code, adding three specific constraints ensures the resulting code is 100% video-ready:

  • Self-Contained File: Require inline CSS and JavaScript with zero external CDN dependencies.
  • Deterministic Time or CSS Keyframe Loop: Specify a loop cycle (e.g. 4s or 6s) so start and end states match perfectly.
  • Fixed Aspect Ratio Viewport: Dictate dimensions like 1920×1080 (16:9 landscape) or 1080×1920 (9:16 portrait).
