Part 1: Exporting GSAP Timelines to MP4

GreenSock (GSAP) provides an internal ticker that synchronizes tweens. To guarantee 100% frame synchronization inside D3motion, simply bind your master timeline:

GSAP Master Timeline Template 
const master = gsap.timeline({ repeat: -1 });

master.to(".card", {
  y: -50,
  rotation: 6,
  duration: 1.5,
  ease: "power3.inOut"
})
.to(".badge", {
  scale: 1.2,
  duration: 0.8,
  ease: "back.out(1.7)"
}, "-=0.5");

Part 2: Exporting Three.js & WebGL Scenes

The secret to pristine WebGL export is deterministic stepping: incrementing scene rotation and particle fields by a fixed delta in your render loop rather than querying Date.now():

Three.js WebGL Deterministic Stepper 
let virtualClock = 0;
function animate() {
  virtualClock += 0.016666; // Fixed 60 FPS delta
  particles.rotation.y = virtualClock * 0.8;
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}
requestAnimationFrame(animate);
